02 / YOUR FIRST MOVE

Where should we start?
Choose what matters to you.

Choose an area. See what you can learn, then take a ready brief to your agent.

This is a planner. A selection does not run an audit or grant access.

Local rules + expert review

What should I fix before release?

  • Findings with source locations and the conditions that make them matter.
  • Lockfile dependencies; current OSV data with separate consent.
  • A repair order, a minimal change and a check for the result.
Scope & limits

Eight local rules detect selected patterns. Authorization and application logic need a separate code review.

$cyber-defense Prepare a pre-release review of my project. Propose an exact file list. After approval, check dependencies, secrets and risky settings. Separately propose a review of authentication, authorization and data flow. Distinguish tool evidence from model judgment.

Reply in English. Reuse existing consent within its scope. Finish with the top three actions, evidence, limitations and an HTML report; PDF only with permission to start the local browser. This brief requests a plan, not access, data sharing or changes.

08 / FAQ

Quick answers
before you start.

Security policy
Which part is the program, and which is the skill?

The skill guides conversation and analysis in your AI agent. The local CLI collects selected evidence and builds reports. This website explains the capabilities and prepares a brief; it does not scan your computer or accept files.

What is actually checked?

Coverage depends on the approved mission. The CLI provides eight local rules, dependency inventories, report imports and a passive website check. Application logic, databases and agent configurations need expert review. Reports distinguish evidence, model judgment and missing data.

What do I get after a review?

A local HTML report with priorities, impact, evidence, a repair plan and verification steps. PDF export requires permission to start your local browser, or you can use Print → Save as PDF. The panel shows progress and run history.

What leaves my machine?

The CLI collects evidence without calling a model. OSV lookup shares package names, versions and ecosystems with separate consent; website checks contact the named site. Codex, Claude Code and other hosts may send conversation content to their provider. Share only the minimum reviewed material.

Will the agent fix issues automatically?

It prepares a proposed change and rollback. Applying it requires your decision. Retesting confirms only what can be checked again in the same scope; an alert disappearing from an imported report is not proof of a fix.

What does it cost?

The project is MIT licensed. The local CLI and synthetic demo need Node.js 22+ and a repository download, without npm package installation. Your chosen AI host has its own account requirements, limits and possible charges.

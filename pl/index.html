02 / TWÓJ PIERWSZY RUCH

Od czego zaczynamy?
Wybierz to, co ma znaczenie.

Wybierz obszar. Zobacz, czego się dowiesz, i zabierz gotowy brief do swojego agenta.

To planer. Wybór nie uruchamia audytu ani nie udziela zgody na dostęp.

Lokalne reguły + przegląd ekspercki

Co poprawić przed wdrożeniem?

  • Ustalenia z lokalizacją w kodzie i warunkiem wystąpienia problemu.
  • Zależności z lockfile; aktualne dane OSV po osobnej zgodzie.
  • Kolejność napraw, minimalna poprawka i sposób sprawdzenia wyniku.
Zakres i ograniczenia

Osiem lokalnych reguł wykrywa wybrane wzorce. Autoryzacja i logika aplikacji wymagają osobnego przeglądu kodu.

$cyber-defense Przygotuj przegląd mojego projektu przed wdrożeniem. Zaproponuj dokładną listę plików. Po zatwierdzeniu sprawdź zależności, sekrety i ryzykowne ustawienia. Osobno zaproponuj przegląd uwierzytelniania, uprawnień i przepływu danych. Odróżnij wyniki narzędzi od oceny modelu.

Odpowiadaj po polsku. Wykorzystaj już udzielone zgody w ich zakresie. Na koniec podaj trzy najważniejsze działania, dowody, ograniczenia i raport HTML; PDF tylko po zgodzie na uruchomienie lokalnej przeglądarki. Ten brief jest prośbą o plan, nie zgodą na dostęp, wysyłanie danych ani zmiany.

05 / TWOJA KONTROLA

Jasny zakres.
Ty ustalasz granice.

Agent korzysta z udzielonej zgody w ustalonym zakresie. Nowe pliki, wysyłanie danych i zmiany wymagają osobnej decyzji. Raport pokazuje, co zostało sprawdzone.

  • Nie atakuje i nie pisze exploitów
  • Nie testuje cudzych systemów
  • Nie zgaduje haseł
  • Nie ukrywa swoich działań
  1. L0
    Doradza

    Wyjaśnia i planuje. Niczego nie dotyka.

    domyślnie
  2. L1
    Czyta pliki

    Tylko dokładnie zatwierdzoną listę, przez 24 godziny.

    approve --yes
  3. L2
    Zagląda do komputera

    Programy i otwarte porty. Bez nazwy komputera i użytkownika.

    inventory --yes
  4. L3
    Pyta internet

    Nazwy, wersje i ekosystemy pakietów do OSV; pobranie CISA KEV.

    --share-package-names
  5. L4
    Sprawdza Twoją stronę

    Kilka zwykłych zapytań GET. Zero ruchu atakującego.

    --authorized
  6. L5
    Zmiany

    Nigdy sam. Przygotowuje poprawkę i sposób cofnięcia. Wdrażasz Ty.

06 / TWÓJ MODEL

Skill w agencie.
Albo samodzielny program.

Podłącz subskrypcję Claude lub ChatGPT, klucz OpenRouter albo lokalny model. CLI zbiera dowody, a model tłumaczy je prostym językiem, odpowiada na pytania i układa plan naprawy — w terminalu (chat) i w lokalnym panelu (ui).

  • SUBSKRYPCJA

    Claude Code

    Twoja subskrypcja Claude Pro/Max przez zalogowane CLI.

    connect --provider claude-code
  • SUBSKRYPCJA

    OpenAI Codex

    Twoja subskrypcja ChatGPT Plus/Pro przez codex exec w trybie read-only.

    connect --provider codex
  • KLUCZ API

    OpenRouter

    Jeden klucz, setki modeli. Klucz z OPENROUTER_API_KEY.

    connect --provider openrouter --key-stdin
  • KLUCZ API

    Claude API

    Klucz Anthropic z ANTHROPIC_API_KEY. Domyślnie claude-opus-5-5.

    connect --provider anthropic
  • KLUCZ API

    OpenAI API

    Klucz OpenAI z OPENAI_API_KEY.

    connect --provider openai
  • LOKALNIE

    Ollama

    Lokalny model na 127.0.0.1. Nic nie opuszcza komputera.

    connect --provider ollama --model llama3.2
cda · model bridge

# 2. wybierz model

# 3. zobacz, co zostanie wysłane

08 / FAQ

Krótkie odpowiedzi
przed startem.

Polityka bezpieczeństwa
Co jest programem, a co skillem?

Skill prowadzi rozmowę i analizę w Twoim agencie AI. Lokalny CLI zbiera wybrane dowody i buduje raporty. Ta strona prezentuje możliwości i pomaga przygotować brief; nie skanuje komputera ani nie przyjmuje plików.

Co naprawdę zostaje sprawdzone?

Zakres zależy od zatwierdzonej misji. CLI ma osiem lokalnych reguł, odczyt zależności, import raportów i pasywną kontrolę strony. Logika aplikacji, bazy danych oraz konfiguracja agentów wymagają przeglądu eksperckiego. Raport rozdziela dowody, ocenę modelu i brak danych.

Co dostaję po przeglądzie?

Lokalny raport HTML: najważniejsze ustalenia, ich znaczenie, dowody, plan naprawy i sposób weryfikacji. PDF powstaje po zgodzie na uruchomienie lokalnej przeglądarki lub przez Drukuj → Zapisz jako PDF. Panel pokazuje postęp i historię.

Co opuszcza mój komputer?

CLI zbiera dowody bez wywoływania modelu. Odpytanie OSV wysyła nazwy, wersje i ekosystemy pakietów po osobnej zgodzie; kontrola WWW łączy się ze wskazaną stroną. Codex, Claude Code i inne hosty mogą przekazywać treść rozmowy swojemu dostawcy. Udostępniaj tylko niezbędny, sprawdzony materiał.

Czy agent naprawi problem sam?

Przygotuje propozycję zmiany i sposób jej cofnięcia. Wdrożenie wymaga Twojej decyzji. Retest potwierdza tylko to, co da się ponownie sprawdzić w tym samym zakresie; zniknięcie alertu z importowanego raportu nie jest dowodem naprawy.

Ile to kosztuje?

Kod projektu jest dostępny na licencji MIT. Lokalne CLI i syntetyczne demo wymagają Node.js 22+ oraz pobrania repozytorium, bez instalacji pakietów npm. Wybrany agent AI ma własne wymagania konta, limity i ewentualne opłaty.

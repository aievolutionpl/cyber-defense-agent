Zasady bezpieczeństwa
Co faktycznie działa w wersji 0.1?

Lokalny przegląd wskazanych plików czterema prostymi regułami, import JSON w formacie cda.scan.v1 i SARIF 2.1.0, raport Markdown oraz porównanie przed i po. Zakres ma jawną listę plików, wygasa po 24 godzinach i blokuje dowiązania. To wąski punkt startu — pełny skaner zależności, skan web/API, sieć i chmura pozostają w planie.

Czy potrzebuję zgody na audyt?

Tak. Sprawdzaj wyłącznie zasoby, do których masz uprawnienia. Agent najpierw przedstawia katalog i dokładną listę plików, a następnie czeka na zatwierdzenie. Zgoda na demo obejmuje tylko syntetyczną kopię przykładu. Strona nie przyjmuje domen, kodu ani danych do skanowania.

Które dane mogą trafić do dostawcy modelu?

Narzędzia CLI przetwarzają pliki lokalnie, bez API modeli i telemetrii. Codex lub Claude Code mogą przekazać dostawcy modelu prompt, podsumowanie narzędzia i fragmenty raportu, które włączysz do rozmowy. Skill zabrania otwierania surowych importów w kontekście modelu. Przejrzyj zredagowany raport przed udostępnieniem — nazwy plików też mogą być poufne.

Czy agent zmienia lub uruchamia mój projekt?

Nie. Narzędzie nie instaluje zależności, nie uruchamia skryptów projektu i nie wdraża poprawek. Raporty zapisuje w katalogu .cda zaufanego repo agenta. Demo zmienia wyłącznie własną tymczasową kopię przykładu. Kontrola zakresu w CLI nie zastępuje izolacji systemowej ani ograniczeń innych narzędzi hosta.

Czy zniknięcie ustalenia oznacza, że problem naprawiono?

Nie zawsze. Status „potwierdzona poprawka” wymaga tej samej lokalnej reguły, aktualnego pliku, zgodnego odcisku i powtórnej kontroli. Brak wpisu w drugim imporcie oznacza „brak danych do potwierdzenia”. Wynik jednej reguły nie potwierdza bezpieczeństwa całego systemu.

Ile kosztuje uruchomienie i czy trzeba zakładać konto?

Kod projektu udostępniamy na licencji MIT. Samo demo CLI wymaga Node.js 22+ i nie wykonuje płatnych wywołań. Strona nie wymaga konta. Do pracy z modelem potrzebujesz osobno zainstalowanego Codex lub Claude Code oraz dostępu do modelu zgodnie z planem danego dostawcy.

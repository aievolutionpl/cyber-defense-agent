P0Baza danychexpert review - model judgmentexpert-review

Table public.orders is readable by anyone: row-level security is off

Co może się stać

Anyone who opens the shop can download every customer's orders and addresses with the public key shipped in the page.

Co zaobserwowano

pg_tables.rowsecurity = false for public.orders; role anon holds SELECT.

Jak to naprawić

ALTER TABLE public.orders ENABLE ROW LEVEL SECURITY; add a policy USING (auth.uid() = customer_id). Rollback: DISABLE ROW LEVEL SECURITY.

Jak sprawdzić poprawkę

Re-run the pg_tables query, then request the table with the public key: it must return only the caller's rows.

P1Kodexpert review - model judgmentexpert-review

Order lookup trusts the ID in the URL (missing ownership check)

Co może się stać

A logged-in customer can read another customer's order by changing the number in the address bar.

Co zaobserwowano

src/routes/orders.ts:42 loads the order by req.params.id without comparing it to the session user.

Jak to naprawić

Filter the query by the session's customer id and return 404 when it does not match.

Jak sprawdzić poprawkę

Request another account's order id: expect 404. Add a regression test.

# Emerald hero and generated artwork

## Direction

Graphite surfaces, emerald primary accents and a restrained violet highlight. The hero is simplified to a short headline and one illustrated defensive sequence; the interactive report now lives in the workflow section. Real HTML text, controls and the image alternative remain available without motion or JavaScript.

The picture is a concept illustration, not evidence of a live network scan. The four stages describe the supported local-file demo: approved scope, dependency signal, human-reviewed remediation and conservative retest. The roadmap link explicitly distinguishes network scanning from v0.1. No CLI capability changed in this visual iteration.

## Original image

- Generator: built-in imagegen (not the API/CLI fallback).
- Project asset: `apps/site/public/assets/defense-network-emerald.webp`.
- Source generated as 1536 × 1024 PNG; delivery encoded locally as 1200 × 800 WebP, 56,792 bytes. No composition edits after generation.
- Visual review: coherent central processor and four connected modules, graphite material, dominant green, one amber fault and a restrained violet edge; no logos, people or generated lettering.
- The original PNG is preserved locally in the generated-image directory and release outputs. Runtime text and annotations are real DOM, not baked into the bitmap.

### Final generation prompt

Create an original premium 3D editorial cybersecurity illustration for the Cyber Defense Agent website. Wide landscape 3:2 composition. A restrained isometric miniature infrastructure diagram on a very dark graphite (#0a1010) seamless background: a beautifully machined central smoked-glass green AI processor, connected with thin precise emerald light traces to four low-profile charcoal server / code modules. One small amber diagnostic fault on one module, a translucent emerald scanning plane passing through the infrastructure, one restrained violet edge reflection. Concept is authorized defensive analysis, evidence and human-reviewed remediation; no destructive attacks. Professional industrial design, museum-quality product lighting, soft shadows, subtle brushed metal, glass and fine bevelled edges, clean disciplined symmetry, generous negative space around the assembly, no clutter, no people, no hooded hackers, no padlock or giant shield, no logos, absolutely no text or tiny labels. Make the objects feel tactile and expensive, with depth and a coherent compact composition, green as main accent, violet under 5 percent of image. Designed to blend into a graphite landing page hero and double as an infographic illustration. No gradients rainbow, no neon cyberpunk city, no busy circuit wallpaper.

## Motion implementation

React state and a 3.8-second stage timer drive four short captions. CSS supplies a scan beam, stage progress and text arrival. IntersectionObserver, document visibility, the shared motion dock, manual selection and reduced-motion preferences gate playback. Choosing a stage holds it; replay deliberately restarts. Focus pauses unattended playback; explicit replay can resume while focused. Observers, listeners and timers are cleaned up on unmount.

This is original requested presentation functionality, not a replacement implementation of unresolved transitions-agent recipe fixes. The previous Polish/Revamp license status is unchanged; no new service fix or purchase is claimed.

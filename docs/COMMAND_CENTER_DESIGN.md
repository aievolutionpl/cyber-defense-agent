# Command-center design and evidence

Status: locally verified; release evidence in RELEASE.md. This is a product presentation, not a launched paid campaign or measured conversion experiment.

## Direction

Audience: experienced AI coding-agent operators preparing a release or a maintenance change. Situation hypothesis: shipping quickly can leave security review and update planning until later. No customer quotes, incidence rates or conversion lift are invented.

The headline connects code creation to a defensible review workflow. Graphite/navy backgrounds, stronger Manrope typography, blue-to-violet accents and a real interactive report replace the previous dominant shield image. The circuit graphic connects code/configuration/inventory to evidence/plan/retest. Protection tabs explain dependency, configuration and maintenance signals. The sole main CTA opens the actual repository; the demo is a secondary path.

## Claims and evidence

- E01: four local rules and conservative import/retest, verified by deterministic tests and the synthetic demo. No full-SAST, exploitability or universal-protection claim.
- E02: update inventory review is implemented in tools/updates.mjs. It processes approved offline JSON, never queries or updates a host. Security priority is operator-supplied, not independently validated CVE data.
- E03: Cursor https://cursor.com/docs/skills and Antigravity https://antigravity.google/docs/skills document .agents/skills discovery. Product sessions remain unverified.
- E04: Lovable https://docs.lovable.dev/features/skills documents Markdown imports; https://docs.lovable.dev/features/knowledge documents instruction context. Bundled local CLI availability and session behavior are not verified.
- E05: Cursor construction is original visual choreography, with independent random Bézier paths and short pauses. No source from unlicensed swarm-cursors was copied. Visible labels are simulated roles, not connected hosts.

## Motion service

transitions-agent 0.11.2 initially scored the repository 71, but included historical exports. The source-only site scan before Polish scored 78. The owner chose Revamp, but the service refused it on the current Free license. The owner then chose Polish. TLS verification succeeded using Node's OS certificate store, without disabling certificate validation.

Polish applied a reduced-motion guard and incorrectly mapped long decorative animation loops (including the 44-second host marquee) to 500ms; the service could not apply its globals.css edit exactly. The unsafe-to-read speed regression was reverted to the pre-service timings; the valid reduced-motion guard remains. The scan's component/menu findings were not manually replaced with a homemade service fix. The separately requested original cursor-construction feature is implemented in the reusable motion skill. The final source score is 78; visual/browser checks are recorded in VERIFICATION.md.

# Motion direction and asset provenance

Style lock: near-black forest/graphite, pale mint, brushed titanium, smoked glass. Large Manrope headlines, IBM Plex Mono for evidence. Depth comes from material, precise borders and button bevels. No random particles, hacker hoodies, neon gradients or invented customer proof.

Keep: exact-scope consent, static audit scenario, conservative retest, actual GitHub links, keyboard tabs and copy controls. Change: light Polish-only composition to dark English default plus a full Polish route; add an original security sculpture, visible defense overview, onboarding and bounded agent choreography.

The renderer-neutral contract is `motion-project.json`. The site uses native CSS/WAAPI/RAF in the existing Next/React stack; FFmpeg creates one lightweight media loop. No GSAP/Three.js installation is needed. Video is silent. The page is recomposed at mobile widths, not delivered as a cropped desktop screenshot.

## Storyboard and controls

1. Hero: readable headline/CTA on the left; generated security core behind an interactive evidence window on the right. A periodic 8-second camera drift is decorative only.
2. Scroll: Scout, Builder and Verifier trace thin frames around marked, real DOM elements. A burst ends after 1.5 seconds; no idle rendering loop. Mobile uses one cursor and no target translation.
3. Audit: interactive controls stay static and usable. Before/after chart values are synthetic and explicitly labeled. Onboarding choices assemble a deterministic plan.
4. Pause dock: freezes CSS motion, stops cursor RAF/WAAPI and pauses hero video. Reduced-motion preference changes work while mounted. Hidden documents and offscreen video stop rendering. Coarse-pointer devices keep the poster instead of autoplaying video.

## Original hero asset

`assets/defense-core-source.png` was generated with the built-in OpenAI image generation tool for this task. The local source copy is retained. The image was visually inspected for shape, edge consistency, composition and absence of unintended text/faces/hands. It is an illustration, not a real security device or audit result.

Generation brief: premium photorealistic industrial 3D security core; monumental brushed titanium monolith with a shield cutout; smoked glass layers and dark plinth; graphite/forest surfaces with restrained mint edge lighting; right-weighted composition with the left 40% dark negative space for text. No words, logos, people, hacker clichés, pink/purple neon or ornamental clutter.

The WebP poster is a local optimized derivative (1600×800). The MP4 is a locally animated still (8 seconds, 30 fps, 1600×800, H.264, no audio), not a generative video model output. Both are first-party page assets; no remote video tracker is embedded. Loop zoom: `1.015 + 0.015*sin(2*pi*frame/240)` with centered crop.

## Cursor provenance

The `DhvanilPatel/swarm-cursors` README and `califa/swarm-site` informed the concept only. The former is a browser extension and declared no reuse license at review time. No code was copied. The original reusable implementation lives in `skills/agent-build-scroll/assets/` and is covered by this repository's MIT license.

Visual/behavior evidence is recorded in `docs/VERIFICATION.md` after the actual browser review. Browser emulation is separate from physical-device or battery/performance testing.
